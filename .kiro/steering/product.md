# 产品

## 定位
SDK-DBAgent 是基于 **claude-agent-sdk** 构建的 NL2SQL（自然语言转 SQL）智能数据库助手，运行于 **OneDBA** 平台之上。用户可以用自然语言描述查询需求，Agent 通过 OneDBA 工具集完成找库、找表、生成 SQL、校验与执行，最终以对话和表格形式返回结果。

## 核心能力

### 1. 自然语言转 SQL
用户用自然语言描述查询需求，Agent 优先调用 `query_database`，由专用 NL2SQL 管道（`生成 → 验证 → 修复 → 语义规则`）自动生成并执行只读 SQL。

### 2. 数据库探索
通过对话即可浏览有权限的数据库、跨环境搜索表名、查看表结构、选择当前数据库上下文。

### 3. 多轮对话
支持上下文感知的追问：修改查询条件、切换数据库、细化需求等。服务端保存最近对话历史和已选数据库，用于构建后续 prompt。

### 4. 流式输出
通过 SSE 实时推送 Agent 推理文本、工具调用开始/完成、SQL 提取结果和最终回答。也提供同步接口和 WebSocket 双向通信接口。

### 5. 安全可控
- `query_database` 只生成 SELECT/WITH 查询
- `execute_sql` 只允许 SELECT/SHOW/DESCRIBE
- 生成 SQL 会校验字段、表名和危险语句

### 6. 语义口径
内置语义规则引擎，将“有效订单”“GMV”“支付成功”等业务概念映射为明确 SQL 口径；无法确认的规则以候选语义呈现给生成器，避免模型自行编造枚举值或业务条件。

### 7. 可观测与评测
支持 Langfuse trace/span/指标采集，并提供 `tests/evaluation` 批量评测 CLI，用于评估 SQL 正确性、回答质量、延迟、工具调用次数和 token 使用量。

## 目标用户
需要在 OneDBA 平台上查询数据库、但不想手写 SQL 的内部数据分析师和开发人员。

## 核心价值
- 无需事先了解 SQL 语法或数据库表结构
- 通过 OneDBA 统一接入多种数据库类型（MySQL、TiDB、StarRocks 等）
- 通过工具约束、SQL 校验和语义规则降低错误 SQL 与口径偏差
- 实时可见 Agent 的推理、工具调用和 SQL 执行情况
