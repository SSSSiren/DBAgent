# Product Overview

DBAgent 是一个 **NL2SQL（自然语言转 SQL）智能数据库助手**，运行在 OneDBA 平台上，面向得物内部团队。用户用自然语言描述查询需求，Agent 自动发现表、生成 SQL、验证安全性并执行——无需用户掌握 SQL 或了解表结构。

## Core Capabilities

1. **NL2SQL 流水线**：多阶段自然语言到 SQL 的转换，包含 LLM 生成 → 语义规则注入 → 安全校验 → 自动修复的闭环，而非简单的 prompt-to-SQL。

2. **智能数据库发现**：Agent 自主导航未知 schema，支持跨库关键词搜索、数据库列表浏览、表结构探查、上下文自动选库，用户无需显式指定表名。

3. **多轮对话上下文**：跨轮次维护会话状态，支持追问细化、中途切换数据库，注入对话历史、摘要、长期记忆（OpenViking）和查询偏好到每轮 Agent 上下文。

4. **安全分级 SQL 执行**：二级安全模型——只读查询（SELECT/SHOW/DESCRIBE/EXPLAIN）自动执行（自动附加 LIMIT 500 安全上限），所有写操作（INSERT/UPDATE/DELETE）和 DDL（CREATE/ALTER/DROP/TRUNCATE）直接拦截，不执行。

5. **可观测的流式 Agent**：ReAct 推理循环通过 SSE 和 WebSocket 实时推送到前端，每一步（LLM 推理、工具调用、SQL 提取、最终响应）都可追踪。Langfuse 集成提供 trace、token 统计和性能可观测性。

6. **HDC 数据底座**：离线 LLM 管线将数据库 schema 转化为四层业务语义描述（列→表→关系→库），存储于 OpenViking 资源目录，在线检索时注入 Agent 上下文，减少 Agent 面对陌生数据库时的 `find_table→describe_table` 盲搜往返。

## Target Use Cases

- **即席数据探索**：用户不知道表名和 SQL 语法，用自然语言描述需求，Agent 自动完成发现→生成→执行。
- **迭代式数据分析**：用户从宽泛查询开始，逐步追问细化（"按类别拆分"、"只看前 5 名"），Agent 维护上下文重建完整查询。
- **带安全护栏的 SQL 直执**：懂 SQL 的用户直接提交查询，系统验证安全性——只读放行，写操作和 DDL 全部拦截。
- **数据库 Schema 探索**：用户通过对话方式浏览数据库、搜索表、查看表结构，了解可用数据。

## Value Proposition

- **降低数据库访问门槛**：非技术人员和分析师无需 SQL 和表结构知识即可查询数据库。
- **消除手动 Schema 发现**：`find_table` 工具支持多关键词搜索、回退扫描、表注释语义匹配，跨多库多环境自动定位。
- **内置安全与治理**：二级执行模型确保用户不会意外修改或破坏数据——只读查询自动放行，写操作和 DDL 直接拦截，同时保证读查询的流畅体验。
- **平台集成而非独立**：运行在 OneDBA 平台上，复用已有的数据库连接、权限和访问控制，无需管理额外凭证。
- **流式交互体验**：SSE/WebSocket 实时展示 Agent 推理过程，提升透明度和信任感。
