# 产品

## 定位
SDK-DBAgent 是基于 **claude-agent-sdk** 构建的 NL2SQL（自然语言转 SQL）智能数据库助手，运行于 **OneDBA** 平台之上。用户可以用自然语言描述查询需求，Agent 自动生成、验证并执行 SQL，最终以表格呈现结果。

## 核心能力

### 1. 自然语言转 SQL
用户用自然语言描述查询需求，Agent 通过专用 NL2SQL 管道（`生成 → 验证 → 修复`）自动生成并执行 SQL。

### 2. 数据库探索
通过对话即可浏览有权限的数据库、按关键词跨环境搜索表名、查看表结构、了解数据分布。

### 3. 多轮对话
支持上下文感知的追问：修改查询条件、切换数据库、细化需求等，Agent 理解对话历史并做出相应调整。

### 4. 流式输出
通过 SSE 实时推送 Agent 的推理过程、工具调用和 SQL 执行进度到前端。同时支持 WebSocket 双向通信。

### 5. 安全可控
- 只读查询自动执行
- 写操作需用户确认
- DDL 操作被拦截

## 目标用户
需要在 OneDBA 平台上查询数据库、但不想手写 SQL 的内部数据分析师和开发人员。

## 核心价值
- 无需事先了解 SQL 语法或数据库表结构
- 通过 OneDBA 统一接入多种数据库类型（MySQL、TiDB、StarRocks 等）
- 实时可见 Agent 的思考过程、工具调用和 SQL 执行情况
