**生成 SQL**: `SELECT status_code, COUNT(*) AS cnt FROM order_record GROUP BY status_code ORDER BY cnt DESC`
**参考 SQL**: `SELECT status_code, status_desc, COUNT(*) AS order_count
FROM order_record
GROUP BY status_code, status_desc
ORDER BY order_count DESC;`
**LLM 评判**: 生成SQL只按status_code分组，忽略了status_desc，而原始问题要求统计每种status_code和status_desc组合的数量，两者语义不同。生成SQL结果中相同status_code的不同status_desc被合并，导致结果与参考SQL不一致。
