## 结论

HDC-SM方案（HDC + SQL 记忆）应比基线方案有以下改善：

1. **准确率提升**: HDC 提供准确的表结构和字段描述，减少表/列幻觉
2. **工具调用减少**: SQL 记忆复用历史成功的 SQL 模式，减少试错查询
3. **延迟变化**: HDC 检索和 SQL 记忆注入会增加少量准备耗时，但可能减少 Agent 盲目探索的轮次
